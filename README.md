# mitchellspaulding.com

Mitchell's Game Room: Mitchell's own site, about the games he makes and the things he likes. It is one page, `index.html`, with no build step.

The Quackers game itself lives at https://quackersgame.com (repo `tannerspaulding/quackersgame`). This site only links to it; no game code belongs here.

Kid-safe rules: first name only, no school, town or other location, no contact form or comments.

Served by GitHub Pages from `main` at https://mitchellspaulding.com.
