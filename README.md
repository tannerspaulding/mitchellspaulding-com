# mitchellspaulding.com

Mitchell's site. Right now it holds a very basic first version of **Quackers**, his duck-hunting game: move between areas with the arrows, go through doors, find hidden ducks and fill the Duck Log.

Served by GitHub Pages from `main` at https://mitchellspaulding.com.

## Look and feel

Quackers uses the "Pond Morning" brand: the swim-ring Q logo, the explorer duck, pond colours, and the Grandstander, Andika and Patrick Hand fonts. The shared drawing code lives in `brand/brand-art.js` (logo and mascot), with SVG copies of the logo, mascot and icon beside it.
